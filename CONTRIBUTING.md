# Contributing

We are not accepting pull requests to this repository.

## Interview candidates

If you are a candidate interviewing with Homage, do not open a pull request or push to this repository. Please also do not fork it. Instead, make your own copy:

```sh
git clone git@github.com:homageapp/2026-dec-case-challenge.git
cd 2026-dec-case-challenge
```

Do your work in your own copy and share it as instructed by your interviewer.
